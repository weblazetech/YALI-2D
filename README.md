# Yali Dental Clinic — "Guardians of Your Smile"

A modern, responsive landing page for **Yali Dental Clinic**, engineered with Next.js 14 (App Router), TypeScript, Tailwind CSS, and Lucide Icons.

## 🌿 Brand Palette
- **Base Canvas:** `#fffbf6` (Warm, non-sterile off-white)
- **Primary Brand / CTAs:** `#49674a` (Forest green)
- **Accent / Badges:** `#d7f5d8` (Soft mint)
- **Body Text:** `#383434` (Deep charcoal slate)

## ✨ Key Features
- **Floating Island Navigation:** Rounded glassmorphism capsule with single-row desktop layout and mobile drawer.
- **Interactive Before & After Smile Makeover Slider:** Split-screen drag handle comparison widget for Clear Aligners, Porcelain Veneers, and Guided Implants.
- **Bento Grid Treatments:** Asymmetric cards showcasing signature cosmetic procedures, surgical implants, and same-day emergency triage.
- **Editorial Clinician Showcase:** Profiles highlighting specialist credentials, fellowships, and bedside philosophies.
- **Direct Scheduling Modal:** Interactive booking form with dynamic service pre-selection and confirmation states.
- **Responsive Architecture:** Calibrated for mobile viewports (375px+) up to 4K displays.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.17+ or later
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
